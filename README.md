# **Challenge Águia Branca🦅**


# **Objetivo🎯**

O projeto tem como objetivo auxiliar na análise dos projetos, ideias e orientações, buscando auxiliar o time por completo, melhorando a comunicação garantindo que os operadores possam expressar ideias, ao mesmo tempo que os gestores acompanham o andamento de projetos e analisam as sugestões, podendo aceitar e priorizar essas ideias. Enquanto isso, os líderes podem de forma fácil e eficaz enviar orientações e alterá-las ou excluí-las quando necessário. 


# **Banco de dados🗃️**

O banco de dados requerido nas regras de negócio é não relacional, então, a equipe optou pelo uso do MongoDB que foi aplicado em aula.


# **Backend💻**

Para o Backend a exigência é o uso de API Rest, a opção do time foi o uso do .NET(C\#), logo foram usados Visual Studio e Swagger para testes antes do consumo, além do uso do JWT e criptografia como requerido nas regras.


# **Frontend🖍️**

No Front, a exigência é um aplicativo mobile, usando Kotlin, que terá consumo vindo diretamente da API.


# **Últimas atualizações🔄️**

O projeto no momento conta com uma aplicação mobile usando dados mokados. A API e o banco de dados ainda estão em desenvolvimento, seguindo os critérios citados anteriormente.
